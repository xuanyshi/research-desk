StatsPAI: A Unified, Agent-Native Python Toolkit for Causal Inference and Applied EconometricsStatsPAI：一个面向因果推断与应用计量经济学的统一、智能体原生 Python 工具包 AI

Biaoyue Wang, Scott Rozelle

The Journal of Open Source Software

本文介绍 StatsPAI 这一开源 Python 工具包，旨在为实证研究者提供统一的因果推断与应用计量经济学接口，覆盖回归与面板模型、工具变量、现代双重差分与断点回归、合成控制、匹配及异质性处理效应估计，并包含诊断、稳健性检验与报告生成功能。该工具包的特色是“智能体原生”：每个已注册函数暴露机器可读的 schema 和结构化失败元数据，使大语言模型驱动的研究助手能够自动发现估计器、比较备选方法并获取模型假设信息。StatsPAI 通过统一报告界面与可解析接口，降低了多方法比较和自动化因果分析的实现门槛。

Olga Trofimova, Leah Böttger, Sacha Bors, Yating Pan et al.

Nature Communications中科院1区 TopJCR Q1IF 18.1

该研究利用UK Biobank中71,343名参与者的眼底彩照，微调基础模型RETFound预测时序年龄，平均绝对误差2.85年，并定义视网膜年龄差。结果发现该年龄差与多种心肺代谢特征、炎症、认知表现、全因死亡、痴呆、癌症及心血管事件相关；全基因组分析识别出与长寿、代谢、神经退行和年龄相关眼病有关的基因。性别分层显示模型性能一致但生物学特征不同，女性更涉及视网膜血管，且绝经后视网膜年龄差升高，临床关联趋近男性模式。
